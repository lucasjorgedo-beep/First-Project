# First-Project

Um teste de primeiro projeto.

## Hambúrguer Perdido

Um mini jogo de aventura em pixel art no navegador. Você controla um guerreiro armado com uma espátula lendária para recuperar o grandioso hambúrguer roubado pelo Cachorro-Quente do Mal.

### Como executar

Abra `index.html` em um navegador moderno ou sirva a pasta com um servidor estático simples:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
