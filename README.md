## Executar os projetos Python

Entre na pasta de cada projeto e execute o comando correspondente:

```bash
# FinanceControl
cd projects/finance-control
python main.py

# TaskFlow (em outro terminal, a partir da raiz)
python projects/taskflow/main.py add "Estudar Python"
python projects/taskflow/main.py list

# CSV Insights
python projects/csv-insights/main.py caminho/para/arquivo.csv
```

## Executar testes

Execute cada suíte na pasta correspondente:

```bash
python -m unittest discover -s projects/finance-control/tests -v
python -m unittest discover -s projects/taskflow/tests -v
python -m unittest discover -s projects/csv-insights/tests -v
python -m unittest discover -s projects/testlab-qa/tests -v
```
