# CSV Insights

Ferramenta de análise exploratória de planilhas CSV com Python puro.

## O que faz
- Conta linhas e colunas.
- Identifica células vazias por coluna.
- Calcula soma, média, mínimo e máximo em colunas numéricas.
- Mostra até cinco valores mais frequentes em colunas categóricas.
- Lê arquivos UTF-8 e UTF-8 com BOM.

## Executar
\`\`\`bash
python main.py caminho/para/arquivo.csv
\`\`\`
## Testes
\`\`\`bash
python -m unittest discover -s tests -v
\`\`\`
Python 3.9+. É um resumo exploratório inicial, não substitui uma análise estatística completa e não altera o arquivo original.
