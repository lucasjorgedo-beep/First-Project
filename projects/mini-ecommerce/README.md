# Mini E-commerce — Domingues Store

Protótipo responsivo de loja virtual feito com HTML, CSS e JavaScript puro, sem instalação de dependências.

## Funcionalidades
- Catálogo de produtos demonstrativos.
- Busca por nome e filtro por categoria.
- Carrinho com adição e remoção de unidades.
- Cálculo automático do subtotal.
- Layout adaptável para celular e computador.

## Executar
Abra o arquivo \`index.html\` em um navegador moderno.

## Limites importantes
É somente um protótipo de front-end. Não possui banco de dados, cadastro/login, estoque, cálculo de frete, checkout real ou integração com Mercado Pago/Correios. Produtos e preços são fictícios e nenhuma compra é realizada.
