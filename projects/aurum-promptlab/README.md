# Aurum PromptLab

Construtor interativo de prompts para praticar engenharia de prompt.

## Recursos
- Campos para papel, objetivo, contexto e restrições.
- Seleção do formato esperado da resposta.
- Montagem de prompt estruturado.
- Cópia do resultado quando o navegador permite acesso à área de transferência.
- Validação para exigir um objetivo.

## Executar
Abra \`index.html\` em um navegador moderno.

## Limitações
A ferramenta organiza texto no próprio navegador. Não envia prompts para modelos, não utiliza chave de API e não gera respostas de IA. Uma integração real exigiria backend seguro e configuração de um provedor.
